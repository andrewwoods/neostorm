# Keymaps


## Primary Keymaps

* Add `<leader>0` **Commit**: Opens LazyGit main window
* Add `<leader>1` **Project Files**: Displays all project files in a sidebar
* Add `<leader>2` Bookmarks: Not yet implemented
* Add `<leader>3` **Find**: Display menu of search types
* Add `<leader>4` Run: Not yet implemented
* Add `<leader>5` Debug: Not yet implemented
* Add `<leader>6` Problems: Not yet implemented
* Add `<leader>7` **Structure**: Display class methods/properties
* Add `<leader>8` Database: Not yet implemented
* Add `<leader>9` **Git**: Opens LazyGit history menu

* Add `<leader>F` **Floating Terminal**: Toggle a terminal in a modal panel
* Add `<leader>R` **Restart**: Close and re-open Neovim
* Add `<leader>S` **Scratches**: Open Scratch files in a sidebar.
* Add `<leader>T` **TODO**: Open TODO items in a QuickFix List.

* Add `<leader><F12>` **Terminal**: Open terminal in a bottom bar.
